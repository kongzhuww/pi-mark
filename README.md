# pi-mark

为 Pi 会话添加收藏标记，并保留现有的自定义 Herdr 集成。

> 当前是现有实现的仓库化整理，不是解耦重构，也不是已经完成的通用插件方案。没有新增 `/marks`，没有实现 `herdr-mark` 插件。你正在使用的本机插件和 Herdr 安装不因创建此仓库而改变。

## 命令

| 命令 | 功能 |
| --- | --- |
| `/mark` | 收藏当前会话，使用会话名或首条用户消息作为标题 |
| `/mark 自定义标题` | 收藏或更新当前会话的标题 |
| `/mark list` | 列出已收藏会话 |
| `/unmark` | 取消当前会话的收藏，不删除会话文件 |

收藏后会话名会添加 `★ ` 前缀；取消收藏时移除该前缀。可在 Pi 自带的 `/resume` 选择器中搜索这个前缀。

只有已落盘、非空的会话文件才能收藏。新建的空会话可能已有预分配路径，但文件尚不存在，此时 `/mark` 会提示稍后重试，不会写入无效收藏。

## 当前集成边界

- 插件把收藏索引写到用户目录下的 `.pi/agent/marked-sessions.json`。
- 索引包含会话 ID、绝对路径、标题、工作目录、profile、时间戳以及历史命令提示字段。
- 保留当前 profile 到 `pi-1` 至 `pi-7` 的命令别名映射。这是原有本机约定，不是 Pi 官方的标准配置。
- 在 Herdr 环境中，通过 `HERDR_SOCKET_PATH` 尝试发送通知；没有 Herdr 时跳过通知。
- **侧栏展示、运行中会话聚焦及 PowerShell 7 恢复由配套修改版 Herdr 实现，不在本仓库里。安装本插件不会给官方原版 Herdr 自动增加收藏侧栏。**
- 当前配套 Herdr 使用结构化会话路径恢复，不执行索引里的 `resume_cmd` 字符串。新收藏的命令提示使用 `--session 路径`；`/mark list` 也会根据路径生成正确提示，不再展示旧记录里的 `--resume 路径`。查看列表不会批量改写历史索引。

## 安装说明

这是开发中的源码仓库，尚未发布到 npm。支持 Pi Git 包安装：

```sh
pi install git:github.com/kongzhuww/pi-mark
```

**如果已经加载了旧的 `session-marker.ts`，不要直接重复安装启用。** 先确认并停用旧入口，否则 `/mark`、`/unmark` 可能重复注册。多 profile 环境也需要分别确认其扩展加载配置。

本仓库创建时没有执行安装或迁移；现有运行环境保持不变。

## 本地验证

使用支持原生 TypeScript 类型擦除的 Node.js 22.18+：

```sh
npm test
```

单元测试只导入本仓库的扩展，在临时用户目录中模拟 Pi 命令上下文，覆盖收藏更新、取消收藏、空会话拦截、损坏索引保护和写入失败保护。

还可以使用已安装的 Pi 做真实 RPC 验证。将 `PI_MARK_PI_CLI` 指向该安装的 `dist/cli.js` 绝对路径，再运行：

```sh
npm run test:rpc
```

RPC 验证通过真实 Pi 包加载、命令派发和会话持久化路径运行。两种验证都不读取真实收藏、不连接真实 Herdr、不发送模型请求；不替代 Herdr 的实际界面点击验收。

## 已知限制

- 保留现有 Herdr 耦合与 profile 约定，暂不承诺通用跨机器恢复。
- 收藏索引仍是单个 JSON 文件，没有跨进程写锁；多个 Pi 进程同时修改时可能互相覆盖。
- 只有索引文件不存在时才视为空列表。JSON 损坏、条目结构异常或读取失败都会中止操作、显示错误，保留原文件，不会自动清空重建。
- 写入使用同目录临时文件加重命名替换，降低中途写坏索引的风险；替换失败时不会截断原索引。这不等于跨进程事务或断电持久化保证。仍建议保留索引备份。
- 未加入自动清理、后台预启动、同步服务或自动更新机制。

## 隐私与许可

不要提交自己的收藏索引、会话 JSONL、账号配置、认证文件或环境变量文件。索引和会话标题也可能包含私人信息。

本仓库未指定开源许可证（`UNLICENSED`），且禁止 npm 意外发布（`private: true`）。公开源码不等于授予开源许可；许可证可在后续明确后补充。
